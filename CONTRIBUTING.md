# Contributing to Amplify Theme Skeleton

Thank you for your interest in contributing to the Amplify Theme Skeleton! This repository provides a starting point for developing and improving storefront themes for **Amplify B2B Commerce**.

We welcome contributions from developers, designers, and the open-source community to improve the theme's design, usability, performance, and overall development experience.

## Getting Started

1. Fork this repository to your GitHub account.
2. Clone your fork to your local development environment.
3. Connect the theme to a running Amplify installation.
4. Follow the project README for installation and build instructions.
5. Start developing and testing your changes.

## What Can You Contribute?

You are welcome to contribute to:

- **UI/UX:** Improve layouts, typography, colors, navigation, and responsiveness.
- **Components:** Develop reusable storefront components and improve existing ones.
- **Pages:** Improve product listings, product details, shopping cart, checkout, and customer account pages.
- **Performance:** Optimize assets, CSS, JavaScript, and page rendering.
- **Accessibility:** Improve keyboard navigation, semantic HTML, and accessibility.
- **Documentation:** Improve setup instructions, examples, and development guides.
- **Bug Fixes:** Identify and resolve existing theme issues.

## Development Guidelines

Please follow these basic guidelines when contributing:

- Keep theme-specific code within the theme repository.
- Avoid modifying Amplify Core functionality.
- Follow the existing project structure and coding conventions.
- Prefer reusable and configurable components over duplicated code.
- Ensure your changes are responsive and work across supported browsers.
- Avoid unnecessary dependencies and large third-party libraries.
- Do not commit environment files, credentials, or sensitive information.
- Test your changes before submitting a pull request.

## Contribution Workflow

1. Create a feature branch from the latest development branch.
2. Make your changes and test them locally.
3. Commit your changes with a descriptive commit message.
4. Push your branch to your fork.
5. Open a Pull Request against this repository.

Suggested branch naming:

- `feature/product-card-improvements`
- `feature/mobile-navigation`
- `fix/checkout-layout`
- `docs/theme-development`

## Pull Request Guidelines

Every Pull Request should include:

- A clear description of the proposed changes.
- The reason for introducing the changes.
- Screenshots or recordings for visual modifications.
- Testing details and any relevant compatibility considerations.

Please keep Pull Requests focused on a single feature, improvement, or bug fix whenever possible.

## Community Guidelines

- Be respectful and constructive.
- Provide helpful feedback during code reviews.
- Discuss major architectural changes before implementing them.
- Respect existing project conventions and licensing requirements.

## Important Notes

This is an evolving starter theme intended to demonstrate recommended development practices for Amplify themes. Some conventions and APIs may change as Amplify evolves.

For significant changes or new architectural approaches, please open an issue for discussion before submitting a Pull Request.

**Thank you for helping improve the Amplify theme ecosystem!**

Happy coding!
